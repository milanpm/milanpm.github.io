# About

Hello, and welcome to MilanPM Tech Blog.

I am a software engineer with experience in industrial and medical software development.

My work and interests include image processing, medical imaging systems, DICOM/PACS, industrial automation, and software engineering.

## What I Am Learning

I am continuously expanding my knowledge through hands-on projects in:

- Artificial Intelligence and Machine Learning
- Digital Image Processing and OpenCV
- DICOM and PACS
- PLC and Industrial Automation
- Software Architecture and Engineering

## Why I Started This Blog

This blog is a place to document what I learn through actual implementation.

Rather than simply collecting theoretical notes, I focus on building small projects, writing source code, testing ideas, and documenting the results.

The general workflow is:

**Learn → Build → Test → Document → Improve**

## GitHub Projects

The source code for many of the projects discussed on this blog is available on my GitHub profile.

I use GitHub to track my learning progress and maintain practical software engineering projects.

## About the Content

Articles on this blog are based on my own learning, development experience, experiments, and research.

My goal is to make each article useful not only as a personal learning record, but also as a practical reference for other developers and engineers.
