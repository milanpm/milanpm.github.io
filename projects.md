## Image Processing

### 01_ImageProcessing

A hands-on Digital Image Processing project using Python and OpenCV.

The project covers fundamental image processing techniques and gradually progresses toward Machine Vision and AI Vision.

**Technologies**

- Python
- OpenCV
- NumPy
- Computer Vision

**Topics**

- Image fundamentals
- Color spaces
- Histograms
- Filtering
- Edge detection
- Thresholding
- Contours
- Shape analysis
- Feature extraction

**GitHub**

https://github.com/milanpm/01_ImageProcessing

## Medical Imaging

### PACS-DICOM-Toolkit

A practical medical imaging project for learning DICOM, PACS, image visualization, measurement tools, and DICOM networking.

**Technologies**

- Python
- PyQt5
- pydicom
- pynetdicom
- DICOM

**Features**

- DICOM image viewer
- Metadata inspection
- Anonymization
- PNG export
- Zoom and pan
- Window / Level controls
- Pixel and HU inspection
- Distance measurement
- ROI measurement
- DICOM networking

**GitHub**

https://github.com/milanpm/PACS-DICOM-Toolkit
